# TechHub PC - Website Thương Mại Điện Tử Kinh Doanh Linh Kiện Máy Tính

Dự án môn học Lập trình Web Nâng cao - Nhóm 2.

## Cấu trúc thư mục dự án

```
website_Thuongmaidientu_linhkienmaytinh/
├── frontend/             # Mã nguồn ứng dụng Frontend (React + Vite + Tailwind CSS)
│   ├── src/              # Các UI components, pages, services
│   ├── index.html
│   ├── package.json
│   ├── vite.config.js
│   ├── postcss.config.js
│   ├── tailwind.config.js
│   └── .env.example
├── backend/              # Mã nguồn Backend API & Cơ sở dữ liệu
│   └── README.md
├── documents/            # Tài liệu phân tích thiết kế và báo cáo đồ án
└── demo_template/        # Bản mẫu thử nghiệm giao diện (Chỉ lưu cục bộ, Git bỏ qua)
```

## Hướng dẫn phát triển Frontend

1. Di chuyển vào thư mục `frontend`:
   ```bash
   cd frontend
   ```
2. Cài đặt các thư viện phụ thuộc:
   ```bash
   npm install
   ```
3. Khởi chạy máy chủ phát triển (Dev server):
   ```bash
   npm run dev
   ```
